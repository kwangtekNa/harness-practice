# UI_GUIDE — 표현 규칙

> 왜 이 문서가 필요한가: 리포트빌더 에이전트가 "예쁘게" 를 제각각 해석하지 않도록, 금융 데이터에
> 맞는 표현 규칙을 고정한다.

## 원칙

- **정직 우선**: 숫자를 반올림해 숨기지 않는다. 천 단위 구분(`1,234,567`)은 표시용일 뿐, 원본 값은 보존.
- **자기완결**: 리포트는 단일 HTML 파일. 외부 CDN·웹폰트·핫링크 금지(사내망 오프라인 동작).
