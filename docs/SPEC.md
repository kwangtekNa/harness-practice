# 정산 규칙 (도메인 단일 출처)  ★제공·수정 금지

> ★ 이 파일은 **완성 제공(고정)** 문서입니다. 다른 docs/ 파일과 달리 빈칸이 없습니다 — 채우지 말고 근거로만 쓰세요.
> 이 문서가 정산 수치의 **권위 있는 출처**다. 코드/문서/리포트는 여기 적힌 값만 쓰고, 지어내지 않는다.
> `execute.py` 의 `build_preamble()` 가 docs/ 를 통째로 프리앰블에 싣기 때문에, 이 규칙은 매 단계 컨텍스트에 자동 포함된다.
> (강의용 가정값 — 실제 제도와 다를 수 있음)

## 1. 수수료 (거래금액 기준)

| 등급 | 요율 |
|---|---|
| online (온라인) | 0.014% |
| offline (오프라인) | 0.048% |
| vip | 0.009% |

- **최소 수수료**: 90원. 계산값이 90원보다 작으면 90원으로 한다.
- **절사**: 원 단위 절사(버림). 반올림하지 않는다.

## 2. 세금

- **증권거래세**: 매도(sell) 에만 0.17% 부과. 매수(buy) 는 비과세.
- 절사: 원 단위 절사(버림).

## 3. 정산 방향

- **매수(buy)**: 고객이 낼 금액 = 거래금액 **+ 수수료**
- **매도(sell)**: 고객이 받을 금액 = 거래금액 **− 수수료 − 세금**

## 4. 해외시장(FX)

- `market = "foreign"` 이면 **환전수수료 0.1%** 를 매수에 더하고 매도에서 뺀다.
- 해외는 국내 증권거래세를 적용하지 않는다.

## 5. 금액 처리 원칙

- 모든 금액은 **정수 원(₩) 단위** 또는 `Decimal` 로 계산한다. `float` 금지(1원 오차 사고 방지).

## 6. CSV 데이터 주의

- `sample-trades.csv` 는 **UTF-8 BOM + CR(`\r`) 혼입** 파일이다. 반드시 `utf-8-sig` 인코딩과 표준
  CSV 파서로 읽는다. 셸 `cut`/단순 `split` 은 컬럼이 어긋날 수 있다.
